# Live News Feeder Web Application

A full-stack, real-time news aggregation platform designed to fetch, categorize, and render breaking news across global, national, and hyper-local levels through an intuitive and responsive web interface.

---

## 📌 Project Overview

The **Live News Feeder Web Application** streamlines daily news consumption by aggregating real-time coverage into structured geographic feeds and thematic categories. Built with a Flask backend and an interactive JavaScript frontend, the application handles dynamic API requests, parses structured JSON payloads, and offers real-time searching and filtering capabilities.

---

## ✨ Key Features

- **Geographic Segmentation:** Dedicated streams for **Global**, **India**, and localized **Ghaziabad** news coverage.
- **Category-Based Filtering:** Multi-category toggle system supporting:
  - 🌐 General News
  - 🎬 Entertainment
  - 🔬 Science & Technology
- **Dynamic Search Functionality:** Real-time keyword query engine to instantly filter articles.
- **Real-Time Data Pipeline:** Seamless integration with RESTful News APIs to fetch up-to-date headlines.
- **Responsive Interface:** Clean, user-centric UI crafted with HTML5, CSS3, and JavaScript.
- **Optimized Data Flow:** Efficient Flask routing and JSON payload processing to minimize rendering latency.

---

## 🛠️ Tech Stack & Prerequisites

### **Technologies Used**
- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **API Integration:** RESTful News APIs
- **Data Format:** JSON
